# First 适配工具实现约定

用户授权：修复生成器审查问题；在 ~/projects/first_ex 保存通用 hook.js、mac/win 配置；提供从此目录安装到 First 的脚本。

- 保留当前已经运行验证的 hook.js，不改写 Windows 行为。
- 生成器默认干跑；--write 写入本项目 config/mac，同时保存证据，不直接改 App。
- 指令匹配宁可停止也不猜：精确 ADD、受限字符串引用、明确三跳链、this/布尔参数来源、控制流到达、唯一候选。
- Mach-O 地址与文件偏移分开，支持非零 __TEXT vmaddr。
- 已验证配置按二进制、配置和 hook 摘要绑定；未知版本需显式选择 CDP 策略，默认安装拒绝未验证配置，--allow-unverified 允许调试安装。
- 安装器默认预览；--apply 执行，先校验全部源文件，再独立备份、原子替换；失败回滚，提供 --rollback。
- 仅管理本次选择的 hook/config；不修改网络、签名或微信登录状态。
- 测试覆盖误引用、不支持指针链、相邻函数、ABI 来源、策略未知、原子写入失败、部分安装失败、回滚。
